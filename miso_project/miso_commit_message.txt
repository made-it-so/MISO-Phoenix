refactor(agent): Harden TDD cascade and fix multi-step loops

This commit represents a full hardening of the MISO "Elastic Intelligence"
architecture, resolving a series of cascading bugs that were
preventing the agent from solving complex, multi-step TDD failures.

The agent is now fully operational and can solve a TDD error that
requires both *new code* and *test-file modification* in a single run.

### 1. Fixed: The "Poisoned Cache Toggle Loop" (The Original Bug)

* **Problem:** The TDD Gate (`verify_plan_in_sandbox`) was "lying." It only
    checked if the *original* error was gone, allowing it to "swap"
    Error A for Error B.
* **Fix:** The TDD Gate is now truly "Code-First." It ONLY returns
    "VERIFIED" if the test command's `exit code` is 0.

### 2. Fixed: The "Groundhog Day" Bug

* **Problem:** The `if __name__ == "__main__":` block in `miso_agent.py` was
    acting as a test harness, overwriting `workspace/` on every run
    and resetting our tests.
* **Fix:** The agent's entrypoint is now "defanged" and no longer
    modifies the workspace on startup.

### 3. Fixed: The "Invalid Plan" Crash

* **Problem:** The Human 👨‍🔬 brain's `{"op": "analysis"}` plan step had no
    `path` key, which caused `os.path.join(..., None)` and crashed
    the sandbox.
* **Fix:** Patched `sandbox.apply_plan` and `miso_agent.commit_plan` to
    be "analysis-aware," correctly handling (skipping/printing)
    this operation.

### 4. Fixed: The "Amnesiac Cascade" Loop

* **Problem:** The Primate 🐒 brain would fail, revealing Error B (e.g.,
    `[arg-type]`). The cascade would then *incorrectly* pass the
    *original* Error A (`[import-not-found]`) to the Human 👨‍🔬 brain,
    causing a logic loop.
* **Fix:** The `run_elastic_cascade` function is now "stateful." It
    captures the `error_output` from a failed TDD verification and
    passes that *new, more accurate* error to the next tier in
    the cascade.

### 5. Fixed: The "Atomic Plan" Failure (The Final Bug)

* **Problem:** The agent got stuck in a loop.
    1.  **Primate 🐒:** Generated Plan A (create `calculator.py`).
    2.  **TDD Gate:** Failed Plan A (revealed flawed test).
    3.  **Human 👨‍🔬:** Generated Plan B (fix `test_calculator.py`).
    4.  **TDD Gate:** Failed Plan B (because `calculator.py` didn't exist).
    5.  The agent looped back to step 1.
* **Fix:** Upgraded the Human 👨‍🔬 brain's simulation logic. It now acts as a
    true "Lead Architect." When it sees the error pattern from the
    Primate's 🐒 failure, it correctly generates a single, atomic,
    multi-step plan that solves *both* problems at once:
    1.  `create_file: calculator.py`
    2.  `modify_file: test_calculator.py`

This final fix proves the 5-tier architecture is sound.
